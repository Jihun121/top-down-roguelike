# 2D 픽셀 도트 던전 로그라이크 프로젝트 인수인계서 (v1.0 — 5단계 MVP 완결본)

* **작성일:** 2026년 10월 19일
* **프로젝트 상태:** 프로토타입 0~5단계 전 과정 구현 완료
* **메인 실행 씬:** `res://world.tscn` (`F5` 키로 즉시 전체 5개 방 진행 가능)

## 2. 5개 던전 방 진행 구조 (`GameManager` 연동)

1. **`ROOM 1 / 5` — 시작의 방 (`res://world.tscn`)**
   * 근접 슬라임 3마리 배치. 모두 처치 시 3지선다 강화 카드 선택 후 북쪽 출입문 개방.
2. **`ROOM 2 / 5` — 교전 구역 I (`res://scenes/room_2.tscn`)**
   * 대칭형 돌기둥과 중앙 상자 엄폐물. 근접 슬라임 3마리 + 거리 유지형 원거리 마법사 2마리 배치.
3. **`ROOM 3 / 5` — 교전 구역 II (`res://scenes/room_3.tscn`)**
   * 십자형 벙커 지형. 강화된 근접 몬스터 4마리 + 원거리 마법사 3마리 복합 교전.
4. **`ROOM 4 / 5` — 정비 성소 (`res://scenes/room_4.tscn`)**
   * 보스전 직전 정비방. 중앙의 보급 상자(`treasure_chest.tscn`)에 접근하면 **체력 +3 회복** 및 **보너스 3지선다 스탯 강화** 획득.
5. **`ROOM 5 / 5` — 심연의 보스방 (`res://scenes/room_5.tscn`)**
   * 최종 보스 **심연의 군주 사이클롭스(`boss_enemy.tscn`)** 및 호위 마법사 2마리 등장.
   * 보스 전용 하단 체력바 표시, 3가지 공격 패턴(3갈래 조준탄, 8~10방향 노바 탄막, 예고 후 고속 돌진) 및 체력 50% 이하 광폭화 구사.
   * 보스 처치 시 잔여 적탄 즉시 소거(`Bullet Cancel`) 및 **VICTORY 결과 화면** 출력.
